[Visual Feature Description]

There are a total of 11 visual features, extracted using the Mediapipe Face Landmarker model.
Most values range from 0 to 100, unless otherwise specified.

Descriptions of the 11 visual features:

- face_ratio: The vertical-to-horizontal ratio of the face. Higher values indicate a longer-looking face.
  This value does not have an absolute standard and must be interpreted relatively.

- eye_open: The degree to which the eyes are open. Higher values indicate more widely opened eyes.

- eye_width: The horizontal width ratio of the eyes. Higher values indicate the eyes are stretched wider horizontally.

- eye_eyebrow_distance: The distance between the eyes and eyebrows.
  Higher values can indicate surprise, tension, or focus.

- eyebrow_slope: The slope of the eyebrows. The baseline is 50.
  Values significantly above or below 50 indicate stronger eyebrow angle changes.
  This value should be interpreted relatively, not absolutely.

- eye_asymmetry: The difference in openness between the two eyes.
  Higher values indicate stronger asymmetry.

- mouth_open: The degree to which the mouth is open. Higher values indicate a wider open mouth.

- mouth_width: The horizontal width ratio of the mouth. Higher values indicate the mouth is stretched wider.

- nostril_open: The width ratio around the nostrils.
  Higher values indicate the nose area is more flared.

- mouth_corner_lift: The degree of mouth corner elevation. The baseline is 50.
  Higher values indicate a smiling expression, lower values indicate a downward expression.
  This value should be interpreted relatively.

- mouth_asymmetry: The difference in height between the two corners of the mouth.
  Higher values indicate stronger asymmetry.

Note:
These values are not absolute truths but reference indicators based on facial landmarks, and may contain errors.
When providing feedback, do NOT rely on a single value.
Always evaluate based on a combination of multiple features.

--------------

[Inferred Emotion Description]

The inferred emotion is predicted using the SigLIP model.

This value may be inaccurate.
Only use it when the user prompt does NOT specify an emotion.

Possible emotions:
"happy", "sad", "angry", "surprise", "fear", "embarrassed"

Only the most confident emotion is provided along with its confidence score (0%–100%).

--------------

[Inferred Face Description]

The inferred face description is generated based on the inferred emotion using the SigLIP model.

This may also be inaccurate.
If the emotion is incorrect, this is highly likely to be incorrect as well.

Therefore, only use it when the user prompt does NOT specify the facial description.

For each emotion, there are 30 labels (total 180 labels).
The system provides the most confident label from the corresponding emotion set along with its confidence (0%–100%).

--------------

[Important Rules]

1. Do NOT judge based on a single numeric value
2. ALWAYS evaluate based on "expressiveness / emotional delivery"
3. The user's intended emotion is the highest priority
4. Numeric values are ONLY supporting evidence, not conclusions
5. Do NOT only criticize — ALWAYS provide actionable improvement suggestions
